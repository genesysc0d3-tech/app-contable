# Código de Ética y Conducta — AlphaCode SpA

**Vigente desde:** 2026-06-25 · **Versión:** 1.0

## 1. Propósito
Establece los principios y conductas esperadas de socios, administradores, trabajadores y prestadores de servicios de AlphaCode SpA, y refuerza el Modelo de Prevención de Delitos.

## 2. Principios
Integridad, legalidad, transparencia, no discriminación, y **cuidado de la información y de los datos personales de terceros**.

## 3. Conductas prohibidas
- **Cohecho / soborno** (incluido a funcionarios públicos o en licitaciones).
- **Lavado de activos**: operar con fondos de origen ilícito o sospechoso.
- **Delitos tributarios**: facturación falsa, evasión, uso indebido de crédito fiscal. *(Especialmente relevante: MassDTE es una herramienta tributaria — está prohibido usarla para emitir documentos falsos.)*
- **Fraude / administración desleal**.
- **Delitos informáticos**: acceso o uso indebido de sistemas o datos de terceros.
- **Conflictos de interés** no declarados.

## 4. Datos personales
El tratamiento se rige por la política de privacidad y la Ley 21.719. **Prohibido usar datos de clientes para fines no autorizados.**
