## Notas
- Se registra **toda** vulneración, se notifique o no. La decisión de notificar (por riesgo) queda documentada.
- Notificar a titulares también si afecta datos **sensibles, económicos/financieros/bancarios** o de NNA. MassDTE trata datos **financieros** → este supuesto aplica con frecuencia.
